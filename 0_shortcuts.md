# Shortcuts  --- paste the snippets in java.json in snippet configuration

### 1. soutf --> System.out.printf()
```
"System.out.printf": {
    "prefix": "soutf",
    "body": [
        "System.out.printf($1);"
    ],
    "description": "System.out.printf()"
}
 ```
 
### 2. soutp --> System.out.print()
```
"System.out.print" : {
    "prefix": "soutp",
    "body": [
        "System.out.print($1);"
    ],
    "description": "System.out.print()"
}
```
